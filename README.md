# Weather Outfit App

Weather Outfit App is a simple application that recommends what to wear based on the current weather conditions and user preferences.

The app combines **weather data** with **style preferences** to suggest suitable outfits for different weather situations.

## Features

- Weather-based outfit recommendations
- User style preference selection
- Example outfit suggestions with images
- Simple interactive interface

## How It Works

1. The user allows the app to access their location and weather data.
2. The user selects their preferred clothing style.
3. The system analyzes weather conditions and suggests an appropriate outfit.
